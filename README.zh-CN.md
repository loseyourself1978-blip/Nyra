# 夜璃 Nyra 1.0 · 本机桌面伴侣

[English](README.md)

Nyra 是 macOS 透明桌面伴侣，提供三套服装、桌面互动、透明角色舞台和可选的 TWOS 只读任务状态。它不能执行或批准工作。TWOS 内置固定版本 Nyra，独立 App 供单独使用桌宠的人安装。

当前仅支持 macOS。Windows 版本开发中，尚无可下载版本。

**Nyra 1.0.0 / build 100**：Apple Silicon 安装包已完成 Developer ID 签名、Apple 公证及 Gatekeeper 检查。[下载本版](https://github.com/loseyourself1978-blip/Nyra/releases/tag/v1.0.0) · [签名、hash 与验证回执](docs/release-1.0/release.json)。旧发行和标签保持；本版发布不代签 Owner 差量验收。
