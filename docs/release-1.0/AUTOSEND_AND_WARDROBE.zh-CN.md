# 五套服装与双语动作语音

Nyra 1.0.5 / 105 指南。匹配完整门禁、签名、公证及确切安装包启动已通过；发行可用性和下载校验以对应 GitHub Release 与回执为准。

## 新服装与声音

“服装”选择器追加白衬衫和红礼服，原黑紫、职场、晚礼服及已保存顺序保留。五套都有站姿和侧卧；新两套使用透明运行帧，支持待机／眨眼、工作、阅读、等待、抬头、环顾、庆祝，以及同服装起身→左右跑／跳跃→落定。动作菜单禁用的可选项没有素材，不以其他服装替代。新两套左右跑采用两帧循环，不声称是八帧动作。

声音 → 中文 → 小田内置短句，或 English → 本机女声。取消静音、开启“跟随动作说话”。中文为 13 段固定离线小田录音；英文为一一对应的 13 句，使用本机已安装的女声（本机验证 Samantha en-US），不是英文小田录音。若没有可用英文声线，面板明确报缺失，不播放中文冒充英文。

新增待机、阅读、移动、跳跃、落定短句；原八句保持不变。动作起始触发一次，保持冷却、不叠音；不会在每一帧或每次状态轮询时重复说话。首次连接、恢复连接和旧快照不重播声音；部分完成、取消、未核验结果不庆祝。手动试播标记为试播，不改变任务结论。

点“关闭”、Esc 或再点声音按钮收起声音面板；关闭面板不关闭动作语音。静音或隐藏会停止播放。用户既有导入、音量、语言和服装偏好保留。
