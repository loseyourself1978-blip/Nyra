# 隐私与权限

Nyra 绘制随包本机素材，不需要浏览器 Cookie、模型 token、云账号或业务文档。TWOS 只读连接仅接受版本化最小事件：生产者/会话/任务标识、序号/事件标识、时间、状态、来源、模拟标记及可选不含正文的证据标识。不得包含指令、代码、账号身份、私人路径、交易或临床正文。

本机传输校验所选对端。Nyra 不能借此写任务、批准、执行命令或发模型请求；未知字段及非法消息被拒绝。重复或重连终态不反复庆祝。显示 URL 只处理显示、隐藏和状态，不选择任意端点或执行文字。

鼠标处理限人物/窗口命中区域，不全局记录键盘、不识屏。导入音频留在本机，系统语音使用已安装声线。偏好和最小工程元数据不是业务日志，不能包含私人消息。独立工程构建即使无诊断参数启动，也使用隔离目录。

文件选择只授权所选文件或端点，不需要全盘访问。录制使用视频须正常系统许可，且为可选项。Nyra 不修改浏览器安全、不购买订阅、不自动注册登录项。
