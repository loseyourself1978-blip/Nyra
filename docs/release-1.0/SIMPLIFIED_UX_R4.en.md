# Nyra 1.0.3 / 103 — simpler controls

This patch changes hover controls and explicit sizing. Prior acceptance of animation, two-pane activity, outfits, transparent stage and sound is preserved. New UI acceptance is separate. The matching release receipt records build, signature, notarization and validation status.

## A · Upgrade only

Quit the old companion normally, then install either the matching TWOS bundle or standalone Nyra. TWOS already includes Nyra; a second installation is unnecessary. Keep preferences. Verify the matching download hash and signing receipt first.

Hover the character: only **+ / Expand** and the real **Stage** button remain. The old square/ruler grip and invisible hit region are removed. Expand **+** to use **Larger / Smaller / Reset size**; wheel/trackpad resizing remains. Reset changes size, preserving outfit, sound, position and task truth. Stage and resize are separate actions.

End here after checking these new controls. Do not recreate a webpage, replay a debate or repeat accepted artwork tests.

## B · First use

Follow INSTALL.en.md, open Nyra and use the hover controls. The stage remains transparent with top safe-area controls and click-through blank regions. **Desktop**, **Stage/Back**, or focused Esc restores the desktop configuration. Sound starts muted; USER_GUIDE.en.md describes optional local previews.

Verify whether the active instance is bundled or standalone if the displayed version differs; do not start competing copies or weaken peer checks.
