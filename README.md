# Nyra 1.0 · local desktop companion

This update fixes local Codex connection freezes and adds bounded, read-only Nyra task labels with a click back to the authenticated running TWOS host.

This version includes five standing/reclining outfits, 13 bundled Chinese Tian action recordings and 13 matching English phrases using an installed local female voice. Sound starts muted; unmute and enable Action voice for eligible transitions, with cooldown and no overlap. Close the panel with Close, Escape or Sound.

Nyra is a transparent macOS companion with five outfits, desktop interaction, a transparent character stage and optional read-only TWOS task status. It cannot execute or approve work. TWOS includes a pinned Nyra copy; the standalone app is for people who want the companion separately.

Currently supports macOS only. A Windows version is in development; no downloadable build is available yet.

Use the Nyra v1.0.6 installer linked above; verify SHA256SUMS and its matching signed/notarized receipt. Historical v1.0.0 stays unchanged. Owner differential acceptance is separate.
