# 夜璃 Nyra 1.0 · 本机桌面伴侣

本版包含五套站姿／侧卧服装、13 段离线小田中文动作短句，以及 13 句使用本机女声的英文对应台词。声音默认静音；取消静音并开启动作语音后按实际动作播放，带冷却、不叠音。声音面板可通过关闭、Esc 或声音按钮收起。

[English](README.md)

Nyra 是 macOS 透明桌面伴侣，提供五套服装、桌面互动、透明角色舞台和可选的 TWOS 只读任务状态。它不能执行或批准工作。TWOS 内置固定版本 Nyra，独立 App 供单独使用桌宠的人安装。

当前仅支持 macOS。Windows 版本开发中，尚无可下载版本。

使用上方 Nyra v1.0.5 安装包，核对 SHA256SUMS 及匹配的签名、公证回执。历史 v1.0.0 保持不变，Owner 差量接受单独记录。
