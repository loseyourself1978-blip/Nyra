# 安装夜璃 Nyra 1.0

> **本轮差量：简洁活动气泡、独立宿主聚焦及英文离线语音。** [操作说明](MINIMAL_STATUS_AND_FOCUS.zh-CN.md) · [实际核验与限制](MINIMAL_STATUS_VERIFICATION.zh-CN.md)。无活动时默认收起；修改操作仍需单独授权。
> **当前控制版：** [单击返回、紧凑任务控制及左右共用 Codex 导航](MINIMAL_STATUS_AND_FOCUS.zh-CN.md)。状态通道保持只读；独立认证控制通道只传递用户主动选定的草稿或动作。旧独立版只读授权不会自动获得控制权。历史版本中仅只读的描述不适用于这个新增控制通道。

Nyra 1.0.8 / 108 · [本次增量](MINIMAL_STATUS_AND_FOCUS.zh-CN.md)

这是独立桌宠。TWOS 已内置固定版本 Nyra，使用 TWOS 时不需要再安装第二个包。

当前仅支持 macOS。Windows 版本开发中，尚无可下载版本。本版仅提供 Apple Silicon（arm64）二进制，声明下限为 macOS 13.0，实测 macOS 27.0.1；不宣称其他系统版本或 Intel 已实测。具体签名与 hash 见发行回执。

1. 在本仓库对应 Release 下载 **Nyra DMG** 及配套 `SHA256SUMS`。工单 ZIP 和 GitHub 自动生成的源码 ZIP 不是安装包。
2. 打开 DMG，把 **Nyra** 拖入 **Applications/应用程序**。推出 DMG，从应用程序打开。只处理 macOS 对这个已签名产品的正常首次启动提示；如果提示签名无效或阻止启动，请先看故障排查，不关闭 Gatekeeper、不移除隔离标记。
3. 透明角色和菜单栏 **◈ 夜璃** 出现。声音默认静音。Nyra 无需注册账号、验证邮箱、模型订阅、Python、Node、Pets 插件，也不会首次联网下载画稿。
4. 移入人物可见区域，点击 **＋** 展开控制环。在“动作”中播放一次受控试播，或一键换装。隐藏人物后，菜单栏仍可恢复显示。
5. 使用 TWOS 内置 Nyra 可直接连接匹配的工作台。使用独立版时，在 TWOS 打开“⋯ 更多 → Nyra 状态 → 连接并授权”，核对准确的独立 App 后按提示授权。已有只读授权时，需单独选择“启用 Nyra 任务控制”才能追加或停止；旧授权不会自动升级。也可只保留状态读取。连接不可用时，本地互动仍可使用，状态如实显示未连接。

**完成结束点：** 安装后的角色显示、控件可用。不需要新建或重做 TWOS 业务任务。

高级校验：在下载文件夹执行 `shasum -a 256 -c SHA256SUMS`。保留清单和发行回执。普通安装不要求使用终端。

## 控件与连接

单击右下角独立悬停舞台箭头进入／退出；滚轮／触控板及“＋”菜单的放大／缩小／恢复默认大小负责缩放；原方块手柄及命中区已移除。返回、动作、姿态、声音、隐藏和退出位于顶部可见安全区，按真实 Dock／菜单位置布局。既有透明素材、五服装和桌面位置恢复保留。

只读状态通道传递左／右／双方来源、最小状态、不透明标识及有限长度的当前会话标题。任一侧真实活动维持工作帧，一侧结束不覆盖另一侧。未知连接保持中性，阅读网页和检查投递不是工作。短动作结束恢复真实基础状态。自动互聊及任务派发由 TWOS 调度。Nyra 不读取完整聊天；独立认证用户控制通道仅转交用户明确输入的草稿或所点击的准确任务动作。

新独立版可通过 TWOS → 夜璃状态 → 连接明确接续。两端 Unix socket 实例和精确签名均核验。旧独立版可能需要正常升级；不移除身份校验。重连只读当前快照，不重放旧工作／庆祝，不复制浏览器凭据或业务文件。
