## R2 控件与连接

单击右下角独立悬停舞台箭头进入／退出；标尺区和滚轮负责缩放。返回、动作、姿态、声音、隐藏和退出位于顶部可见安全区，按真实 Dock／菜单位置布局。既有透明素材、三服装和桌面位置恢复保留。

Nyra v2 只接收左／右／双方来源、最小状态和不透明标识。任一侧真实活动维持工作帧，一侧结束不覆盖另一侧。未知连接保持中性，阅读网页和检查投递不是工作。短动作结束恢复真实基础状态。自动互聊由 TWOS 调度，Nyra 不能派发、批准或读取聊天。

新独立版可通过 TWOS → 夜璃状态 → 连接明确接续。两端 Unix socket 实例和精确签名均核验。旧独立版可能需要正常升级；不移除身份校验。重连只读当前快照，不重放旧工作／庆祝，不复制浏览器凭据或业务文件。
