# 使用夜璃 Nyra 1.0

**R2 验证范围。** 签名候选 TWOS 1.0.2 / 101.50 已通过一次明确启动的真实 ChatGPT↔Claude 三往返：六次提交及六份对应完整回复，没有逐轮手动发送或检查。重开后保留完成状态且不重放。TXT、PNG 和简单文字层 PDF 已取得双方向内容可读证据；原生／合成边界测试另列。匹配完整主回归、新字节公证和制品 hash 见发行回执；公开发行以对应 GitHub Release 为准，工程结果不代签 Owner 接受。


Nyra 是本机视觉伴侣，不是执行代理。它不能批准任务、运行命令、发送消息，也不从聊天正文推断成功。

## 桌面互动

移入人物可见区域触发一次跳跃，指针停留不重复跳。按住人物向左或向右拖动，窗口移动并播放对应方向跑步帧；松开后落定，恢复真实基础状态。角落缩放柄、滚轮和触控板可调整大小，人物移出视野时从菜单“复位位置”恢复。

控制环提供换装、透明舞台、声音、动作、缩放、隐藏和退出。动作是有结束时间的“手动试播”，不改变任务事实，不算业务成功。该服装缺少的可选动作会禁用。试播结束恢复当前真实状态，并尊重 macOS“减少动态效果”。

## 三套服装与舞台

黑紫、职场、晚礼服均有站姿与侧卧运行素材。透明舞台顶部安全区选择服装，并用“姿态”切换站姿/侧卧。侧卧支持眨眼、注视、工作、等待和庆祝试播；跑跳使用同服装“起身→动作→躺回”的帧，不旋转整张站姿冒充侧卧。

舞台是屏幕尺寸的透明窗口，不是黑底系统全屏 Space。空白区可点击下层窗口，人物和控制条仍可操作。点击“桌面”“舞台/返回”，或在舞台取得焦点时按 Esc，恢复原桌面位置、大小和服装。隐藏或退出也会恢复桌面配置，不安装全局键盘监听。

## 任务事实

| 状态 | 外观及含义 |
|---|---|
| 已连接，无活动任务 | 待机 |
| 排队/等待用户 | 等待；请在 TWOS 批准或回答，Nyra 不能代办 |
| 执行中 | 工作 |
| 部分完成/失败/取消/结束但未核验 | 中性待机，保留真实结果提示，不庆祝 |
| 有关联证据的核验成功 | 只庆祝一次，然后回到当前基础状态 |
| 断线/过期 | 中性外观、连接未知，不永久假工作 |

手动庆祝标明试播。网页回复结束不证明本机文件通过验证。启动和重连先读当前快照，不重播旧庆祝。Nyra 不授予整体 Owner 接受。

## 声音与生命周期

声音面板有静音、音量和显式中英文试听，使用已安装系统语音或用户本地导入音频。随包包含两个原创短提示音，不宣传独家生成声线。隐藏后停止帧与悬停计时器及声音；已连接的只读状态查询可继续维持连接事实。退出 Nyra 不停止 TWOS 或模型任务。生产环境内置版与独立版共用偏好，同一用户只保留一个兼容活动实例。

## R2 控件与连接

单击右下角独立悬停舞台箭头进入／退出；标尺区和滚轮负责缩放。返回、动作、姿态、声音、隐藏和退出位于顶部可见安全区，按真实 Dock／菜单位置布局。既有透明素材、三服装和桌面位置恢复保留。

Nyra v2 只接收左／右／双方来源、最小状态和不透明标识。任一侧真实活动维持工作帧，一侧结束不覆盖另一侧。未知连接保持中性，阅读网页和检查投递不是工作。短动作结束恢复真实基础状态。自动互聊由 TWOS 调度，Nyra 不能派发、批准或读取聊天。

新独立版可通过 TWOS → 夜璃状态 → 连接明确接续。两端 Unix socket 实例和精确签名均核验。旧独立版可能需要正常升级；不移除身份校验。重连只读当前快照，不重放旧工作／庆祝，不复制浏览器凭据或业务文件。
