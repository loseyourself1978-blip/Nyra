# Rebuild the fixed English voice recordings

The release stores all 13 generated WAV files in Git. Rebuilding Nyra requires those pinned files, not downloading a model or installing inference dependencies. The standard app build stays offline.

For a deliberate regeneration only, use a disposable Python 3.12 environment with `generation-requirements.lock`. Download the public tiny-voca files named in `model-download.json` from `https://huggingface.co/n4ze3m/tiny-voca/resolve/d94d2a0338fd1e0eab7dd896ec0ad23d8cdf7c14/<path>` into `materials/weights/<path>`. Compare every SHA-256 with that inventory. Download the dizione source at the exact commit in `source-pins.json` into `materials/dizione`, preserving its Apache-2.0 license and data tables. Copy both JSON receipts into `materials`. Do not download or run training data or PyTorch.

Run `python scripts/generate_english_voice.py --materials /absolute/materials --output /absolute/new-cues`. This uses one CPU thread, F2, speed 0.95, unchanged pitch, 24 kHz mono 16-bit PCM. It reads only the fixed English action phrases. No chat, task, account, or credential content is synthesized or uploaded. An existing output directory is refused.

Retain source, model revision, checksums, settings, license texts and listening results. The output checker verifies finite non-silent signal and clipping; it does not prove pronunciation or subjective quality. Listen to every cue before publication. Runtime/platform variation can alter generated bytes; generated audio must receive a new manifest and review rather than silently reusing old acceptance. Cleanup the generation environment after the final audio and receipts are safely retained.

The F2 source voice is synthetic; the author describes its intended adult American female voice and current limitations in the pinned model card. No voice cloning or exclusive ownership claim is made. Chinese Tian 1413 assets and user-imported audio remain unchanged.
