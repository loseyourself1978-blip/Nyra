# 依据、规格差异与目标选择

## A. 附件确认的事实（不改写）

`ASSET_AUDIT.md`：3 张综合设定图、8 张裁片及1张选择参考，合格透明运行图、PSD/骨骼/Live2D/3D与原创音频均为0。主裁片302×517；PNG虽有alpha通道，但背景和标签仍在，不能按“存在alpha”认定抠图成功。

`DELIVERY_REPORT.md`：目前为独立macOS静态预览。拖动、缩放、全屏、隐藏恢复和退出已有对应工程结果。真正动作、TWOS只读联动、声音和Pets创建/选中没有完成。

`MINIMUM_ASSETS.md`：独立运行画布1024×1536；四套首轮状态为idle6、working6、gaze/head5、verified_success6；站姿脚锚点(512,1444)。Pets v2方案为1536×2288、8×11、192×208每格、73必需帧槽与15空格。

`SCOPE_AND_AUTHORIZATION.md`：原授权只涉及独立Nyra工程、静态预览及指定私有仓库上传；不是TWOS业务修改、交易、公开分发或账号权限扩张。

## B. 本轮公开资料核对（2026-10-23）

官方 Pets 页面把桌面创建与网页上传分开：桌面 Settings > Pets > Create pet 会使用捆绑的 `hatch-pet`；网页上传写明透明PNG/WebP、1536×1872、≤20MiB。桌面自定义Pets是本地安装，不自动同步到网页。

官方命令参考仍列出安装流的spriteVersionNumber可为1或2，但该字段本身没有在本次可读页面完整给出各版本逐行含义。

来源：
- https://learn.chatgpt.com/docs/pets
- https://developers.openai.com/codex/reference/commands

**结论：不能将附件v2的11行与网页上传的9行简单认定为彼此对错，也不能拉伸图集。** 先读取用户本机实际目标App、创建skill和预检器，再固定对应layout。当前没有读取用户本机skill，也没有创建Pet。

## C. 本包提供的两个profile

1. `pets_v2_attachment_provisional`：忠实保存附件的11行/73槽方案；目标接受、方向起点及顺序未本机验证。
2. `web_9row_candidate_unconfirmed`：尺寸来自官方网页上传要求；其9行动作映射暂由附件前9行构成候选，**未由官方页面证实**，不能直接作为可安装产物。

两者默认都不能编译正式可安装图集。需将目标版本、实际skill/hash、逐行映射和必要方向映射证据登记在`target_environment.json`，并绑定所选profile hash。

## D. 几何冲突的显式处理（本轮设计决定）

原文件同时要求“四周约8%”与脚锚点y=94%。严格8%底部留白与该锚点不能同时成立。本包优先保留原脚锚点；采用顶部/左右约8%、底部约6%的制作值。此为明确补充，不称原图已符合。

生产画布保持1024×1536，Pets格子192×208。编译采用一个全组共享等比变换，不按每帧人物框自动放大。美术内部16方向从屏幕正上方起顺时针；**这不是未经核验的宿主方向顺序**，必须按实际skill映射。

## E. 本轮能力和权限记录

Runway只读核验：plan=0、purchased=0、total=0；未启动图像、视频、语音生成，未上传参考图。Pets插件检索未返回可调用结果；不据此声称用户本机没有Pets。没有用其他未授权收费路径绕过限制。

附件可供本机开发使用，不等于允许公开图片、发布仓库、换公网图床、读取TWOS私人数据或替用户更换当前活动Pet。私有仓库原上传回执保留；本轮未实时访问/修改远端。
