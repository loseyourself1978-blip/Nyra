# 安装夜璃 Nyra 1.0

适用于 Nyra 1.0.2 / 102。升级后先看 [R3 差量指南](OWNER_REGRESSION_R3.zh-CN.md)，完成对应终点即结束；不重新制作已接受任务。




这是独立桌宠。TWOS 已内置固定版本 Nyra，使用 TWOS 时不需要再安装第二个包。

当前仅支持 macOS。Windows 版本开发中，尚无可下载版本。独立二进制的编译下限为 macOS 13.0；工程实测平台是 Apple Silicon。编译了 Intel 架构不等于 Intel 已实测，具体系统和签名结果以最终发行回执为准。

1. 在本仓库对应 Release 下载 **Nyra DMG** 及配套 `SHA256SUMS`。工单 ZIP 和 GitHub 自动生成的源码 ZIP 不是安装包。
2. 打开 DMG，把 **Nyra** 拖入 **Applications/应用程序**。推出 DMG，从应用程序打开。只处理 macOS 对这个已签名产品的正常首次启动提示；如果提示签名无效或阻止启动，请先看故障排查，不关闭 Gatekeeper、不移除隔离标记。
3. 透明角色和菜单栏 **◈ 夜璃** 出现。声音默认静音。Nyra 无需注册账号、验证邮箱、模型订阅、Python、Node、Pets 插件，也不会首次联网下载画稿。
4. 移入人物可见区域，点击 **＋** 展开控制环。在“动作”中播放一次受控试播，或一键换装。隐藏人物后，菜单栏仍可恢复显示。
5. 需要真实 TWOS 状态时，优先使用 TWOS 内置版。独立版的“连接 TWOS 状态”会要求选择准确的 TWOS App 和其文档说明的本机端点，只读取最小状态。不要选择业务报告、凭据或任意 socket 文件。没有有效端点时仍可本地互动，并如实显示未连接。

**完成结束点：** 安装后的角色显示、控件可用。不需要新建或重做 TWOS 业务任务。

高级校验：在下载文件夹执行 `shasum -a 256 -c SHA256SUMS`。保留清单和发行回执。普通安装不要求使用终端。

## R2 控件与连接

单击右下角独立悬停舞台箭头进入／退出；标尺区和滚轮负责缩放。返回、动作、姿态、声音、隐藏和退出位于顶部可见安全区，按真实 Dock／菜单位置布局。既有透明素材、三服装和桌面位置恢复保留。

Nyra v2 只接收左／右／双方来源、最小状态和不透明标识。任一侧真实活动维持工作帧，一侧结束不覆盖另一侧。未知连接保持中性，阅读网页和检查投递不是工作。短动作结束恢复真实基础状态。自动互聊由 TWOS 调度，Nyra 不能派发、批准或读取聊天。

新独立版可通过 TWOS → 夜璃状态 → 连接明确接续。两端 Unix socket 实例和精确签名均核验。旧独立版可能需要正常升级；不移除身份校验。重连只读当前快照，不重放旧工作／庆祝，不复制浏览器凭据或业务文件。
