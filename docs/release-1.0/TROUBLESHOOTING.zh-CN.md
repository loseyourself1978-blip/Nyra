# Nyra 故障排查

- **看不见人物：** 菜单栏 ◈ 夜璃 → 显示/隐藏；已运行时可从应用程序重新打开。“复位位置”恢复到可见区域，不要先删除偏好。
- **另一版本正在运行：** 从原 Nyra 菜单正常退出，再开需要的版本。TWOS 任务继续，不使用 killall 或同时启动多份。
- **没有任务连接：** 本地动画仍可用。在 TWOS 点击 Show Nyra 并检查只读关联提示；独立启动的 Nyra 可能需要显式选择端点。人物打开不等于已关联任务。
- **工作中但没有新文字：** 查看 TWOS 当前任务和连接状态。Nyra 按事件显示，不按经过时间或隐藏思维猜测。过期连接必须变成未知，保留具体错误，不编造成功。
- **试播回到待机：** 手动动作有结束时间。禁用项表示该服装没有对应可选素材；核心动作见指南。
- **退出舞台：** 点击桌面/返回，或让舞台取得焦点后按 Esc。控制条保持可用，空白区域本来就应穿透。
- **没有声音：** 默认静音。打开声音，选择语言/来源后显式试听。系统语音随本机安装而异，不静默下载声线。
- **macOS 阻止启动：** 核对发行包和回执，记录提示和版本。不要关闭安全设置，也不要把私人凭据贴进支持记录。

只提供产品版本、相关错误及非敏感复现步骤；不要发送任务正文、账号资料、报告、token 或端点秘密。
