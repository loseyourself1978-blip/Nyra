# V3 身份、alpha与坐标锁定

## 身份不变

夜璃 / Nyra，约25岁的成年女性。黑紫猫耳、深色长卷发、紫水晶眼睛，角色解剖左侧紫晶饰物，黑颈饰和紫晶坠、细黑紫尾和紫色尾饰。采用选定对比图下半区V3，不回退到红发V3或白紫V2。

成熟、清透、亲近、优雅和可爱通过眼神、短微笑、肩颈线及克制手势体现。默认不透明黑紫连衣裙、完整内衬、深色袜与短跟靴。不做未成年/幼态比例、内衣外露或情色姿态。此约束沿用原ART_BIBLE，不是更换既有人设。

## 母版和动作共用坐标

- 画布1024×1536 RGBA/sRGB；中立support anchor=(512,1444)。
- top/side约8%、bottom约6%的安全区。跳起保留真正空中位移，不再把脚移动回地线。
- 坐姿另建seated体系，不硬套站姿锚点。本P0优先全部站姿，避免混入未对齐坐姿。
- 固定相机、角色比例、光源和左右身份。背景、文字、标号、桌面、棋盘格和浮动符号均不在运行PNG中。
- 允许工具做统一全组对齐；任何变换留原始尺寸和矩阵；不分别裁紧每张图。

## Alpha不能只检查文件模式

1. 真实背景像素alpha=0；背景不能只是半透明；人物核心通常alpha=255。
2. 文件四角/边界透明，人物不裁切；头发发缘可抗锯齿，不是整体半透明。
3. 在白底、黑底、灰棋盘格和紫色底各看一次边缘，排除白边/黑边/抠掉眼白、衣服和手指。
4. 数值检查不能识别人脸、衣服走光、手指数量、贴纸边缘或身份一致性，仍要人工审。
5. 生成器不能直出透明时，允许基于真实分割做背景去除并记录处理，不能仅把画面alpha统一调低。

## 分层备选

如逐帧难以保持一致，可在不改变脸型与衣装的前提下用完整画布分层PNG+z-order JSON。最低包含后发/刘海/左右发束、脸/双眼/眼睑/眉/口、猫耳、躯干、左右上臂/前臂/手、衣服前后片/袖/遮罩、尾根/中/尾尖及道具。每层记录pivot、父级、遮挡和隐藏补画。

分层完成不等于绑定完成；禁止将海报裁成几条后整体摇摆当作精细Live2D。绑定路线仍应导出同样可检查的实际PNG帧，不能绕过帧检查。
