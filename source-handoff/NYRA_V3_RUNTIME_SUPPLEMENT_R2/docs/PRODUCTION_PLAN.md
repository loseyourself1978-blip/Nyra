# 素材生产计划：从0个运行资产到可安装动画

所有下面的画稿和动作均为待制作，不因本文件存在而标PASS。

## P0：默认服装先成为真正动画

唯一母版先过检查，再批量沿用同一图像参考。P0包含20张唯一PNG：
- 中立母版1张；
- idle新增5张，连同母版构成6槽；
- working 6张；
- gaze/head四向4张，连同母版中向构成5槽；
- verified_success新增4张，首末引用同一母版，构成6槽。

共23槽不等于23张独立表演。共享关系在JSON中明确。idle自然闭环；working固定道具与手部连续；gaze是头与眼共同改变而躯干保持；success一次播放1.9秒后回中立，不循环庆祝。

只完成一个母版不能宣告P0通过；只把全身缩放/平移也不能通过。关键检验：眨眼形状、肩部与发梢的局部变化、腕指动作、头眼联动、点头/挥手的实际姿态差异。

## P2：换装和其余表演

首个补充服装只做职场中立PNG，与默认同脸同姿态同锚点；在完成所有动作前只能叫“静态运行换装”，不能叫完整动画换装。

晚礼服、8工作姿态、8交互姿态、12表情及7嘴形在`EXTRA_ART_AND_VOICE.md`列出。它们仍有独立缺口，不阻止先完成默认P0/Pets，但最终全套声明必须逐项有文件。

## 图像生产顺序

1. 用原V3参考锁定成年身份，生成真正完整透明母版；检查无遮挡、五指、手脚尾完整、服装覆盖。
2. 母版审核后固定其hash，后续调用引用母版，不每帧独立随机人物。
3. 每次只制作一个动作族，按明确帧位生成；原始输出和必要抠图/归一化处理留痕。
4. 工具检查alpha/尺寸/边界；人工审身份、解剖、衣装和连续播放。
5. 不合格画稿只补画对应帧/局部，不用外观漂移的替代人设凑数。
6. 保留每张实际输出分辨率、处理和hash；不把302×517放大成“原生1024×1536”。
7. 打包前完成目标profile核验；编译后还需宿主预检和实际播放。

## 完成判定

ART_P0_READY：所有20张及四动作实际播放通过。
ATLAS_TECHNICAL_READY：目标profile确认、每个必需格有合格素材、15空格透明、文件大小与宿主预检通过。
PET_CREATED：实际创建回执和唯一ID已取得。
PET_LIST_VISIBLE：刷新后在目标列表中看到同一ID。
PET_SELECTED：用户明确选中且显示该角色。
FULL_NYRA：不能仅因Pets可见就授予；声音、换装、TWOS联动等需各自真实证据。
