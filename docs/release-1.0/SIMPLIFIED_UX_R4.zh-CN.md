# Nyra 1.0.3 / 103 — 控件精简

本补丁只调整悬停控件与明确缩放入口。既有动画、双侧工作状态、服装、透明舞台及声音接受保留；新 UI 接受单独记录。构建、签名、公证及验证状态见匹配发行回执。

## A · 只做升级差量

正常退出旧桌宠后安装匹配 TWOS 内置版或 Nyra 独立版。TWOS 已自带 Nyra，无需重复安装；保留偏好。安装前核对下载 hash 和签名回执。

移入人物：仅保留 **＋／展开** 和真正的 **舞台／全屏** 按钮。原方块／标尺手柄及其不可见命中区移除。展开后使用 **放大／缩小／恢复默认大小**；滚轮／触控板缩放仍可用。恢复默认大小只改变尺寸，不重置服装、声音、位置或任务事实。缩放与进入舞台是不同操作。

完成新控件检查即结束。无需制作网页、恢复旧辩论或重验已接受素材。

## B · 首次使用

按 INSTALL.zh-CN.md 安装后打开 Nyra，使用悬停控件。透明舞台保留顶部安全区菜单和空白穿透。**桌面**、**舞台／返回** 或舞台取得焦点时的 Esc 恢复桌面配置。声音默认静音，显式本机试听见 USER_GUIDE.zh-CN.md。

## C · 接续已有使用

正常重开保留服装、尺寸、位置和声音偏好。TWOS 状态通道双向核验身份，只读最小状态；不读取正文、文件内容、路径、账号或凭据，Nyra 不能执行或批准任务。版本不符时核对当前可见实例是内置还是独立版，不启动竞争副本、不放宽对端检查。

当前发行支持 macOS Apple Silicon；Windows 开发中、无下载版本。部署下限不证明所有旧系统均实测，具体覆盖见回执。历史媒体不能代替本轮 UI 证据。
