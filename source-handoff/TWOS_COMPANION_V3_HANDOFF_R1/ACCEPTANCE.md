# 工程与美术验收清单

## Gate A：素材
- 读取本次实际图片附件并映射8张图；未获得的标MISSING，不拿参考图冒充新套图。
- 主立绘和派生姿态是同一成年角色；黑紫、发饰、主服装不变。
- 素材真实alpha、足够留白、头脚尾不裁切、无明显手指错误、无棋盘格底纹。
- 可运行素材从图板裁切/归一化并记录hash；全图海报不能直接当桌宠贴上。
- 至少8工作状态、8交互姿态、12表情在角色预览器可查看；没有的如实标缺。
- 眨眼、工作手部、视线/头部跟随、成功动作至少4个可区分动画，不用一张图整体缩放冒充。

## Gate B：桌面体验
- 原生App能单独启动/退出，不抢键盘焦点，不覆盖重要点击位置。
- 透明外侧区域不会吞掉底层页面输入；拖动和菜单仅在可见命中区域生效。
- 一键隐藏/退出/静音；忘记位置或屏幕断开时能通过菜单恢复。
- 多屏、Retina、缩放、Spaces、休眠唤醒、系统减少动态效果有实际记录；未验证不宣称通过。
- 首次默认不开机自启，不要求全局键盘监听、麦克风、录屏或辅助功能权限。

## Gate C：状态真实性
- 模拟事件明确带SIMULATION；真实TWOS连接单独标LIVE/CONNECTED。
- completed + unverified不得庆祝；PARTIAL保持待完成提醒；失败回执不改成成功。
- verification pass和Owner accepted分开；只有授权状态来源支持时才显示对应反馈。
- 重复/乱序事件不重复说话、不回退终态；多任务切换不串角色语音。
- 断线显示未知，不用计时器伪造进度；所有动作不调用LLM。
- 点击桌宠不会批准任务、交易、读取私人内容或执行Codex。

## Gate D：语音
- 声音可完全关闭，默认静音；专注模式下不会被成功播报打断。
- 系统TTS预览与专属录音分别标记；专属音色未产出就NOT_PRODUCED。
- 无私有文本进入TTS，静音/取消/断连时无排队音频继续播放。

## Gate E：隔离与性能
- 独立目录、独立进程和配置；原TWOS启动、任务、成果与验收不变。
- 不生成/修改交易、调度、审批、财务或医疗事件。
- 本机测量空闲5分钟、连续演示2分钟、隐藏1分钟CPU/内存/刷新率；目标见animation_states.json。记录硬件和采样口径，不用未经测量的“低占用”宣传。
- 隐藏停止渲染；无动作时降帧；日志不记录任务内容和鼠标轨迹。

## 真实接入测试
先用工程实例产生至少一个真实运行中事件和一个真实终态，关闭/重连后不重复触发；不能为桌宠测试重放Owner历史任务。若现有只读事件接口不可获得，先完成独立模拟预览，标LIVE_INTEGRATION=BLOCKED，不改数据库偷取状态，也不宣称已集成。

## 交付分级
ASSET_DESIGN、RUNTIME_ASSETS、DESKTOP_APP、SIMULATION_DEMO、TWOS_LIVE_READONLY、SYSTEM_TTS_PREVIEW、CUSTOM_VOICE、OWNER_ACCEPTANCE各自有状态。
没有真实运行时PNG/动画不能称FULL_PET；没有实际语音不能称定制女声完成；没有只读事件回执不能称TWOS实时联动已通过。
